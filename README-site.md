# OmniThings website

The public website is available at [omnithings.ai](https://omnithings.ai/).

Its source and deployment configuration are maintained in the dedicated
`OmniThings/OmniThingsWeb` repository. This repository owns the GitHub organization
profile in `profile/README.md`. Website changes should be made in the website
repository so that the organization profile remains independent.

The source extraction preserved the deployed content and Cloudflare Worker.
